01

Locked brand hues

Fixed company identity. Every derived colour on this page is built from these four and nothing else. Introducing a fifth system colour means checking it against both canvases first.

Electric Cyan

The single functional accent — links, focus, active UI. One highlight per view.

#00C6E0

Accent Magenta

Rationed to one moment per page, or retired to data-viz. Never paired with cyan as decoration.

#EC4699

Deep Navy

Dark-mode canvas. Roughly 95% of the surface area in the product.

#050B16

Near White

Light-mode canvas. Warm paper-neutral — deliberately not pure grey or pure white.

#FAFBFC

The cyan → magenta pairing belongs to the logo mark. Anywhere else it reads as decoration, and decoration is what this system spends its restraint avoiding.

02

Dark mode palette

canvas #050B16

Both accents clear 4.5:1 on navy, so cyan and magenta can carry body-size text here. That freedom does not survive the trip to light mode.

03

Light mode palette

canvas #FAFBFC

Pure cyan drops to 2.00:1 on paper and pure magenta to 3.43:1. Both stay correct as brand hues for the logo, illustration, data-viz, and large bold type — but the moment either one carries small text, swap in the Ink variant.

The swap, in one sentence

This sentence contains a cyan link. In dark mode it is pure Electric Cyan at 9.53:1. In light mode it is Cyan Ink at 4.81:1. Same role, same token name, different value — which is why nothing in the codebase should ever hardcode #00C6E0 for text.

05

Texture & motion

No glow. Negative space and hairlines do the work effects would otherwise be asked to do.

Grain, not glow

A fractal-noise overlay at 4.5% sits on the canvas of this page. It is a fixed layer, never intercepts a pointer, and reads as paper tooth in light mode and film grain in dark.

--np-grain-opacity: 0.045

Hairlines, not shadows

Cards get a 1px border in the mode's hairline colour. Anything that needs a meaningful edge — an input, a focus ring — uses the stronger border token instead, because a 1.36:1 hairline can't carry that job.

--bc-hairline / --np-border-strong

Voice pulse

The one signature animation: bars breathing in and out. It marks loading and active listening, and it is content-true — this is a voice product, so the loading state looks like a voice.

In motion

Reduced motion

Timing

Micro 130ms for hover and toggle, standard 240ms for menus and modals, large 360ms for canvas changes. Ease-out entering, ease-in exiting, ease-in-out for moves. Only transform and opacity animate.

--np-dur-micro / -standard / -large

07

Usage rules

  • R1Cyan is the only functional accent. One colour for active, focus and links — no competing accents.
  • R2Magenta is rationed to one moment per page, or confined entirely to data-viz. On this page it spends that budget on failure states, which should be rare by design.
  • R3Never combine cyan and magenta as a gradient for decoration. That pairing belongs to the logo mark.
  • R4In light mode, always ask whether a colour is carrying text (use the Ink variant) or acting as a large graphic element (the pure hue is fine).
  • R5Both modes are built from the same four hues. Never introduce a fifth system colour without checking it against both canvases.
  • R6Colour is never the only signal. Every state encoded in colour also carries a glyph, a label, or both.

Do / Don't

Do

  • ✓Use Bricolage Grotesque for anything meant to feel like a statement.
  • ✓Let type and space carry the premium feeling.
  • ✓Use the Ink variants for cyan and magenta body text in light mode.
  • ✓Keep both modes built from the same four brand hues.

Don't

  • ✕Default to Inter, ever.
  • ✕Reach for glow, gradient or shadow to signal quality.
  • ✕Ship pure Electric Cyan or Accent Magenta as small text on the paper canvas.
  • ✕Let dark and light drift into two different brand feels.
08

Audit & open items

What the contrast bench found when it recomputed every published ratio, and which tokens this page had to invent to meet the craft floor. The invented ones are namespaced --np-* so they're impossible to mistake for blessed system tokens.

Published ratios that don't match the maths

Dark · Text Primary

Published as 9.5:1. The true ratio for #FAFBFC on #050B16 is 19.02:1 — looks like the cyan row's value was copied up.

Dark · Text Secondary & Tertiary

Published 4.6 and 3.0. Actual 6.66 and 3.63. Understated, so nothing unsafe shipped — but the tertiary has more headroom than the doc admits.

Light · Text Primary & Secondary

Published 17.9 and 5.4. Actual 19.02 and 5.77.

Light · Text Tertiary — the one that matters

Published 3.1. Actual 2.99. It's rounded across the line. Disabled controls are exempt from WCAG, but placeholder text is not — so #8B93A0 should not be used for placeholders in light mode. Darkening it to roughly #767E8B clears 3:1 with no change to the brand feel.

New patterns to promote into the source doc

Focus ring, light mode

§3 assigns light-mode focus rings to pure cyan at 2.00:1. WCAG 1.4.11 asks for 3:1 on focus indicators, so that's a fail. This page uses Cyan Ink (4.81:1) instead. Same fix applies to any cyan icon or border that carries meaning rather than decoration.

--np-focus

Border Strong

Hairlines land at 1.36:1 (dark) and 1.26:1 (light). Correct for dividers, too weak for input borders and other meaningful edges, which need 3:1. Added #3D5170 / #A9A398.

--np-border-strong

Spacing, radius, motion scales

The system defines textures and a signature animation but no numeric scales. Nine spacing steps, three radii, three durations and three easings were needed to build anything at all. These are proposals, not decisions.

--np-space-* / --np-radius-* / --np-dur-*

Semantic status colours

There's no success or danger role, and magenta is rationed to one moment per page — so it can't be the general error colour. This page routes failure through magenta plus a glyph plus a word, but a product with forms will need a proper danger token checked against both canvases.
